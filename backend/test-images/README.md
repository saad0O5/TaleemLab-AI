# Test Images Directory

Place your hand-drawn DC circuit photos (e.g. `circuit1.jpg`, `circuit2.png`, `circuit3.jpeg`) in this folder.

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`

Once you have added photos and added your `GEMINI_API_KEY` in `.env`, run:
```bash
node test-pipeline.js
```
